# KazeGram Desktop

**KazeGram Desktop** — десктопный форк [Telegram Desktop](https://github.com/telegramdesktop/tdesktop) (на базе `v7.4.4`) для Windows без ИИ-надстроек и рекламы, с собственным брендингом, изолированным профилем и настраиваемой иконкой.

---

## Что уже реализовано

- **Полное удаление ИИ-функций**
  - Удалены кнопки, подменю и диалоги AI-редактирования текста и тона в полях ввода, редакторе подписей к медиа и редакторе Instant View.
  - Удалена подсистема `AI Compose` / `Tones`, горячие клавиши, URL-обработчики и промо-блоки Cocoon вместе с неиспользуемыми ресурсами.
  - Отключена AI-суммаризация текста сообщений.
- **Блокировка рекламы**
  - Отключены рекламные посты в каналах, реклама в поиске, видеореклама и спонсорские каналы прокси.
- **Собственный брендинг и изоляция (Windows)**
  - Имя приложения `KazeGram` (`KazeGram.exe`), собственный AUMID, реестр, `tdata`-каталог и переносимый маркер `KazeGramForcePortable/`.
  - Отключено автообновление официального клиента, локализованы строки контекстного меню трея (`Закрыть KazeGram` и др.) и идентификатор клиента для языковых пакетов.
- **Иконка `風 + K` и настройки KazeGram**
  - Белая минималистичная иконка по умолчанию (стилизованный иероглиф `風` + буква `K`) и убраны лишние точки/бейджи непрочитанных с иконки в системном трее.
  - Раздел **Настройки → KazeGram** с выбором цвета иконки в реальном времени: *По умолчанию* (белый), *Под акцент активной темы* и *Свой цвет* (HEX/палитра) с живым превью иконки для панели задач и трея.

## Сборка

### Локальная сборка (Windows x64)

Подготовьте зависимости и инструменты по официальному руководству [docs/building-win.md](docs/building-win.md) (скрипт [Telegram/build/prepare/win.bat](Telegram/build/prepare/win.bat), конфигурация через `Telegram/configure.bat`), либо используйте скрипт `build-debug.cmd` в родительской рабочей директории.

### Сборка через GitHub Actions (CI)

В репозитории настроен workflow [`.github/workflows/build-windows.yml`](.github/workflows/build-windows.yml):

- **Ручной запуск (`workflow_dispatch`)**: выбор конфигурации (`Release` / `Debug`) и флага LTO (`enable_lto`).
- **Сборка релиза по тегу (`v*`)**: собирает `Release`, упаковывает портативный архив `KazeGram-<tag>-win64-portable.zip` (с `KazeGram.exe`, `*.dll`, `LICENSE`, `LEGAL` и `KazeGramForcePortable/`), считает `SHA256SUMS.txt` и прикрепляет файлы к GitHub Release.
- При необходимости укажите секреты репозитория `TDESKTOP_API_ID` и `TDESKTOP_API_HASH` (при их отсутствии используются открытые ключи Telegram Desktop API).
